# Bank : domaine C#

Le projet de départ pour construire le domaine en TDD.

- `src/Bank.Domain` : le domaine, vide pour l'instant. Il ne référence aucun projet ni aucune librairie.
- `tests/Bank.Domain.Tests` : ses tests, avec xUnit.

Il n'y a rien à démarrer, ni base ni configuration. Depuis `jour-2/hexagon/csharp` :

```bash
dotnet test
```

Tant que le projet ne contient aucun test, la commande n'en trouve aucun et se termine sans erreur.
